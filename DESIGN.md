# Design System — One Token Explainers

## Architectural Thesis: One Braided *Journey* Centerpiece, Synchronized Views & Labs

The root entry (`index.html`) delivers **One Token's Journey** as a full-section braided centerpiece: six chapter rooms following `" sat"` (`"The cat sat on the mat"`) interleaved with pooled flat `Diagram` stage bands (`shared/spine-stage-pool.js`) and inline interactive micro-labs. A narrated, auto-advancing tour is the main path: the top bar holds only brand, `Play` and `Mute` (the hero's single start button stands in for Play until it scrolls away), and breadth comes first with equations and specs opt-in per card (`Go deeper`). There is no Basic | Deep switch. **No 3D model appears until the finale:** the Observatory iframe loads on demand, and the summary reveals one "Explore the 3D model" capstone (3D Studio, with a quiet **Cinema 3D Flythrough** link, `journey-tour/index.html?mode=flythrough`) plus an "Other ways to explore" block linking the other editions. Every standalone view (`one-token/`, `end-to-end-swiss/`, `end-to-end-beamline/`, `journey-tour/`, `shared/obs-core.html`) shares the minimalist `44px` top bar (`One Token / <View>` + stage-synced `Views ▾` switcher with 7 hands-on labs) while preserving its own committed visual palette.

## Shared Contracts

- **Single theme source (`shared/theme-tokens.js`):** Defines the 12-stage reader's ground (`#F6F5F2`), plates (`#FFFFFF`), inset (`#ECEAE3`), warm architectural stone/pewter ramp (`#EFECE6` → `#8C877E`, silhouette `#5E6268`), Vermilion token (`#FF4A1C` / `#B8320D` ink), Cobalt attention (`#1E4EC8` ink / `0x265CE0` 3D), Brass cache (`#855D14` ink / `0xCFA03E` 3D), Pine tool (`#1C6B4C` ink / `0x22946E` 3D), and Terracotta training/fault (`#9E3E22` ink / `0xCA4E2E` 3D) tokens once for both CSS custom properties and WebGL materials in `one-token/scene-diagram.js` and `one-token/scene-spatial.js`. Spatial PBR hardware uses the light-to-dark limestone/pewter/slate ramp (`0xDDD8CE` → `0xC6C0B4` → `0xB2ACA0` → `0x969186` → `0x686C72` → `0x525862` → `0x3D434C`; trained tower plates and idle racks use the `0x525862` slate step) over the `#F6F5F2` mineral terrazzo floor; Diagram uses `NoToneMapping` for pure `#FFFFFF` plates and crisp ink edges.
- **Pooled single-WebGL stage hosts (`shared/spine-stage-pool.js`, `one-token/scene-host.js`, `one-token/inspector.js`):** Both the root Braided *Journey* spine (`SpineStagePool`) and the 12-Stage Continuous Reader (`ReaderScene`) share a single `WebGLRenderer` (`Three r160`) across Diagram and Spatial representations with chapter-matched skin adaptation (`light`, `key`, `bp`), SVG poster twins on vacant slots, on-demand idle halting (`0` idle RAF frames), and suspension whenever an Observatory cutaway opens.
- **Cross-page fabric (`shared/suite-theme.css`):** Opts participating pages into `@view-transition { navigation: auto; }` (disabled under `prefers-reduced-motion: reduce`), defines `--suite-ease: cubic-bezier(0.16, 1, 0.3, 1)` and `--suite-bar-h: 44px`, and styles the shared `One Token / <Edition>` masthead grammar, `Views ▾` stage-synced switcher + 7 hands-on lab links, return chip (`← Back to …`), and quiet `"Inspect component in 3D →"` bridge links.
- **Concept deep-linking (`shared/concept-links.js`):** Maps 7 canonical concepts (`tokenization`, `mhc-residual`, `csa-hca-kv` / alias `kv-cache`, `moe-router`, `prefill-decode`, `utf8-sse`, `mcp-loop`) across all explainers using explicit `file://`-safe `index.html` URLs and restores exact reading position via return-chip query params (`from`, `pos`). `journey-story/index.html` redirects cleanly to `../index.html` while preserving query and hash parameters.
- **Micro-lab inheritance (`shared/micro-labs.css`):** Inherits host `--sans`, `--mono`, `--c-acc`, and control radius tokens so every interactive probe looks native in the unified Reader Inspector, Beamline Study, Story, Tour, and Observatory.
- **Transitions:**
  - Unified Reader switches Diagram ↔ Spatial via a bounded cross-fade at the same canonical stop, preserving active stage, token form, and reading position.
  - Story 3D Expand uses FLIP geometry scaling (`380ms var(--suite-ease)`) synced with `obs-core` camera flight.
  - Tour chapter skin changes interpolate smoothly via `applySkinMix()` instead of hard-cutting backdrops.
  - Classic Swiss stays independent of `micro-labs.js` and `obs-file-bridge.js`, never stacking a second WebGL context.
- **Epistemic hygiene:** Every counterfactual failure mode, hardware EP All-to-All dispatch estimate, sampled activation stripe, and causal steering graph is explicitly labeled illustrative and kept distinct from documented Anthropic API and DeepSeek-V4-Pro facts.

## Spatial Production Contract

- **Authored assemblies:** Reusable procedural factories provide the cutting gate, embedding library, 61 chamfered plates with four residual conduits, 384-expert switchyard, brass KV drawers, probability dial, emissive bezeled screen, Pine tool bench, detokenizer, and one clear-coated Vermilion token. Static siblings merge by material; animated and addressed parts retain named meshes.
- **Light and material:** Matte limestone, brushed pewter, satin brass, and glossy signal parts use local generated textures. The shared renderer uses ACES, per-shot exposure, a cached procedural PMREM studio, contact shadows, and a motivated active-mechanism light rather than semantic colors on neutral hardware.
- **Quality and reconstruction:** High/medium/low tiers progressively remove signal glow, environment sampling, curved topology, and resolution. Canonical stop poses reconstruct exactly after forward or reverse navigation; reduced motion snaps directly. Zero idle frames and the static SVG fallback remain mandatory.
- **Camera continuity:** Eye, target, field of view, zoom, and lens shift share an elapsed-time critical damping curve. Flights end at subpixel convergence, then reconstruct the exact authored pose; no timed final snap. Returning from Diagram, resizing, or restoring a suspended/hidden scene fits the current stop immediately. Hidden documents render no scene frames, independently of Inspector suspension.
- **Shot hierarchy:** Corpus, filtering, tokenization, and vocabulary close-ups frame their active mechanism; the model's lifecycle placement does not automatically make it a framing anchor. Model-focused shots retain the complete tower and its explanatory connections.
- **Wayfinding and explanation:** One primary anchored callout uses hysteresis, eased side changes, frame clamping, and a token-obstacle check. Explanation remains available in Read and Present, with a clear bordered action; Present and phone layouts keep the active figure unobstructed. Classic concept links use the same 44px outlined-action language.
- **Annotation proximity:** Prefer short local leaders over viewport corners. Placement scores both the label box and the leader against the projected token, keeps glides within the frame, and retains the current side when alternatives are nearly equal. Phone captions retain the callout text without overlaying the small scene.
- **Narration:** Cue-timed route segments follow written order independently of source MP3 order. Actual media `ended` events are authoritative when file metadata differs slightly from route durations, and deliberate scrolling seeks without pausing active narration. Captions preserve the distinction between corrected text and the unchanged spoken recordings.
